4 · 组件使用规则

跨组件一致性的强制约束，违反即视为设计缺陷。

4.1 间距与对齐

场景规则
组件内边距卡片 24px；卡片内元素间距遵循 8px 网格（8/16/24）
栅格汉字网格：移动 1 列 / sm 2 列 / md 3 列 / lg 6 列
最大行宽正文阅读宽度 ≤ 680px；空状态描述 ≤ 280px

4.2 状态规范

状态视觉表现
默认2px 水墨灰边框 / 静态阴影
悬停上移 2–8px + 阴影加深（按层级）
聚焦朱砂红边框 + 4px 光环（ring-primary/20）
选中淡朱砂背景 bg-primary/10 + 朱砂光环
禁用opacity 0.5 + 禁止光标
加载Skeleton animate-pulse
错误危险色边框 + 文案（实时校验）

4.3 无障碍（A11y）

要求实现
焦点可见focus-visible：2px --ring 轮廓 + 2px offset
语义角色弹窗 role="dialog"；选项 role="option"；列表 role="listbox"
状态属性aria-selected / aria-expanded / aria-hidden
跳转Skip-link 跳至 #main-content
减少动画prefers-reduced-motion 时动画降至 0.01ms

4.4 正反例

✓ 应该✗ 不应该
用 rounded-xl / rounded-2xl 等 token 圆角用 rounded-[28px] 任意值
用 bg-primary / text-foreground 等 token 类内联 style={{color:'#c53d43'}}
深色模式用 .dark 类覆盖 CSS 变量用 Tailwind dark: 前缀覆盖语义色
主操作用朱砂红，辅助操作用水墨灰多处使用高饱和强调色造成噪点
